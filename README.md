# DSO576 Music Project

DSO 576 team project using the Spotify Kaggle dataset.

## Live dashboard

Open the deployed Streamlit dashboard: https://yolanda-music-dashboard.streamlit.app/

The deployed demo uses `spotify_cleaned_sample.csv` (50 rows). It is suitable
for smoke-testing the dashboard workflow, not for full-data conclusions.

### Deployment

- Repository: `yolandaL597/DSO576_Music_Project` (personal fork for hosting)
- Branch: `main`
- Streamlit entry point: `app.py`
- Dependencies: `requirements.txt`
